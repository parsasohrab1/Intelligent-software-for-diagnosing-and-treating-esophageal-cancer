## محدودیت‌ها

* retrospective و روی داده‌های عمومی؛ جایگزین مطالعهٔ prospective یا تأیید رگولاتوری نیست.
* مرحله‌بندی TCGA ترکیبی از ویرایش‌های مختلف AJCC است؛ GSE53624 و ICGC-ESCC فقط ESCC‌اند؛ برای GSE53624 فرض شده M0 (فقط مراحل I–III گزارش شده).
* AUC وابسته به زمان بدون وزن‌دهی IPCW است. امتیاز مدل گسسته است (تعداد مقادیر متمایز آن کم است) و tie‌ها C-index را به ۰٫۵ نزدیک می‌کنند.
* `RiskPredictor` (ریسک ابتلا) با داده‌های case-only قابل اعتبارسنجی نیست و در این گزارش ادعایی دربارهٔ آن نمی‌شود.
