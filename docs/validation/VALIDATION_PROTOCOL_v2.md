# پروتکل اعتبارسنجی v2 — مدل داده‌محور Cox (Pre-registered)

> **این سند قبل از آموزش یا ارزیابی هر مدلی نوشته و commit شده است.**
> زمینه: v1 (`PrognosticScorer` rule-based) در ۵ از ۷ معیار شکست خورد
> ([گزارش v1](REAL_DATA_VALIDATION_REPORT.md)). این پروتکل یک **مدل جدید** را با **همان آستانه‌ها** (بدون تخفیف)
> و فقط یک معیار اضافه (A8) ارزیابی می‌کند. پس از دیدن نتیجه هیچ بخشی از این سند تغییر نمی‌کند؛
> اجرا **فقط یک بار** انجام می‌شود و نتیجه — چه PASS چه FAIL — ثبت می‌شود.

## ۱. مدل

**Ridge-penalised Cox proportional-hazards** (احتمال جزئی Breslow، بهینه‌سازی L-BFGS) با ویژگی‌های baseline ثابت و **از پیش‌تعیین‌شده**
(هیچ انتخاب ویژگی داده‌محور وجود ندارد):

| ویژگی | کدگذاری |
|---|---|
| `age` | سال، استانداردسازی با میانگین/انحراف معیار آموزش |
| `male` | ۱ اگر مرد |
| `t_ord` | T1–T4 → ۱–۴ (ناموجود: میانهٔ آموزش) |
| `n_ord` | N0–N3 → ۰–۳ (ناموجود: میانهٔ آموزش) |
| `m1` | ۱ اگر M1 (ناموجود: ۰) |
| `eac` | ۱ اگر آدنوکارسینوم (در مقابل SCC) |
| `tnm_missing` | ۱ اگر هر یک از T/N/M ناموجود باشد |

* جریمهٔ ridge λ از شبکهٔ `{0.1, 1, 10, 100}` با **۵-fold CV تکرارشده (۳ تکرار، seed=20260507) فقط روی داده‌های آموزش** انتخاب می‌شود (بیشینهٔ میانگین C-index).
* بقای پیش‌بینی‌شده: `S(t|x) = exp(-H0(t)·exp(η))` با H0 برآورد Breslow روی داده‌های آموزش، برای t = ۱، ۳ و ۵ سال.
* **گروه‌های ریسک:** برش‌های tertile از *linear predictor* داده‌های آموزش (Low/Intermediate/High)؛ همان برش‌ها روی داده‌های آزمون اعمال می‌شوند.

## ۲. طرح اعتبارسنجی: Internal–External Leave-One-Cohort-Out (LOCO)

سه کوهورت واقعی (TCGA-ESCA، GSE53624، ICGC-ESCC؛ همان منابع و معیارهای ورود v1). برای هر کوهورت h:
مدل با دو کوهورت دیگر آموزش (و λ با CV داخلی همان دو) می‌بیند و روی **h که هرگز ندیده** پیش‌بینی می‌کند.
همهٔ معیارها روی این پیش‌بینی‌های out-of-sample محاسبه می‌شوند. مدل نهایی قابل‌انتشار روی هر سه کوهورت برازش می‌شود؛
برآورد عملکرد آن همان نتایج LOCO است.

## ۳. معیارهای پذیرش (آستانه‌ها = v1، به‌علاوهٔ A8)

محاسبهٔ C-index/AUC روی پیش‌بینی‌های LOCO و به‌صورت stratified طبق Amendment 2 پروتکل v1.

| # | معیار | آستانه |
|---|---|---|
| A1 | C-index تجمیعی (stratified) | ≥ 0.60 |
| A2 | کران پایین CI 95٪ (bootstrap 2000، seed=20260507) | > 0.50 |
| A3 | C-index در **هر** کوهورت نگه‌داشته‌شده | ≥ 0.55 |
| A4 | AUC(3 سال) تجمیعی | ≥ 0.60 |
| A5 | log-rank بین سه گروه ریسک (tertile) | p < 0.05 |
| A6 | |میانگین S(1y) پیش‌بینی‌شده − KM مشاهده‌شده| تجمیعی | ≤ 0.15 |
| A7 | C-index مدل ≥ baseline «فقط سن» | — |
| **A8** | C-index مدل ≥ baseline «فقط مرحلهٔ AJCC» − 0.01 (مدل نباید از ساده‌ترین مرجع بالینی بدتر باشد) | — |

کالیبراسیون ۳ ساله و ۵ ساله به‌عنوان اطلاعات تکمیلی گزارش می‌شود (بدون آستانه).

## ۴. تحلیل‌های ثانویه (بدون آستانه)

C-index به تفکیک هیستولوژی (EAC/ESCC)، زیرمجموعهٔ TNM کامل، و ضرایب مدل نهایی (hazard ratio با بازهٔ اطمینان bootstrap).

## ۵. قاعدهٔ تصمیم

* همهٔ A1–A8 برقرار → مدل «اعتبارسنجی retrospective روی داده واقعی» محسوب می‌شود و برای ادغام در محصول (به‌عنوان گزینهٔ جدید `cox_v2`) مجاز است.
* هر معیار نقض شود → FAIL گزارش می‌شود، مدل در محصول فعال **نمی‌شود**، و هیچ ادعای اعتبارسنجی مطرح نمی‌گردد.

## ۶. محدودیت‌ها

retrospective و عمومی؛ ویژگی‌های بالینی محدود به baseline موجود (بدون ECOG، درمان، بیومارکر)؛ طول پیگیری TCGA کوتاه است؛ جایگزین مطالعهٔ prospective یا تأیید رگولاتوری نیست.
