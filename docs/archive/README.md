# بایگانی مستندات توسعه

فایل‌های این پوشه، گزارش‌ها و یادداشت‌های وضعیت (status) مربوط به مراحل مختلف توسعه پروژه هستند که در طول فرآیند توسعه با کمک ابزارهای هوش مصنوعی تولید شده‌اند (مانند گزارش‌های تکمیل هر فاز، راهنماهای راه‌اندازی موقت و خلاصه‌های پیاده‌سازی). این اسناد جنبه تاریخی دارند و صرفاً برای مرجع نگهداری شده‌اند؛ محتوای آن‌ها ممکن است قدیمی یا ناسازگار با وضعیت فعلی پروژه باشد.

مرجع رسمی و به‌روز پروژه، فایل‌های زیر در ریشه مخزن هستند: `README.md`، `ARCHITECTURE.md`، `DEPLOYMENT.md` و `CHANGELOG.md` (که به‌صورت جداگانه توسط تیم نگهداری می‌شود). در صورت هرگونه تناقض میان اسناد این پوشه و مستندات اصلی، مستندات اصلی ملاک عمل هستند.
